# Healthcare Data Analysis Using Excel

## Project Overview

This project explores a healthcare dataset using Microsoft Excel to organise healthcare-related information and present it in a structured, accessible format. The workbook includes a healthcare dataset, a report sheet, and a dashboard.

The project demonstrates the use of Excel for working with structured data and presenting information to support data exploration and reporting.

## Project Objectives

- Explore and organise healthcare-related data.
- Examine the dataset's structure and key variables.
- Present information through a report and dashboard.
- Demonstrate practical Excel skills in data handling and visual reporting.

## Tools Used

- **Microsoft Excel** — data organisation, spreadsheet analysis, reporting, and dashboard presentation.

## Workbook Contents

The Excel workbook contains three worksheets:

- **healthcare_dataset** — the main dataset.
- **Health Report** — the report component of the workbook.
- **Dashboard** — the dashboard component for presenting information visually.

## Skills Demonstrated

- Spreadsheet management
- Structured data organisation
- Excel reporting
- Dashboard presentation
- Data visualisation

## Key Takeaway

This project demonstrates how Microsoft Excel can be used to organise healthcare-related data and present it through a report and dashboard. It forms part of my practical learning and portfolio development in data analysis.

## Project Files

- `healthcare_dataset.csv.xlsx` — Excel workbook containing the dataset, report, and dashboard.
